## Find the focus

A useful interface answers three questions: where am I, what can I do here, and what happens next? Begin with one headline and one primary action.

::course-checkpoint{id="purpose"}
I can describe the purpose of this page in one sentence.
::

## Build the first screen

The example uses semantic color utilities so the same page can adopt a different brand without changing its structure.

::code-tree-intersection

```vue [app/pages/index.vue]
<template>
  <main class="bg-default text-default p-8">
    <h1 class="text-3xl font-semibold text-highlighted">Make room for good work.</h1>
    <p class="mt-4 text-muted">A small step toward something you care about.</p>
    <UButton class="mt-6">Start your project</UButton>
  </main>
</template>
```

::

## Check the experience

Move through the page with the Tab key. The primary action should have a visible focus indicator and a label that explains its outcome. Check the same screen in light and dark mode.

::course-checkpoint{id="keyboard"}
I checked the primary action with a keyboard.
::

::note
The visual theme can change. The meaning and order of the page should remain clear.
::
