## A small project. A useful skill.

Build a welcoming page with a clear hierarchy, meaningful actions and room for your content to breathe. This short course combines practical design decisions with a working code example.

## What you will learn

- Give every page one clear purpose.
- Use semantic colors rather than hardcoded values.
- Make actions understandable with a keyboard and a screen reader.

::tip
You do not need a finished brand to start. Make the structure work first, then explore how your identity changes the feeling of the page.
::

## Your learning path

Start with the lesson below. Try the two checkpoints and inspect the project file as you read. Progress in this example stays within the current preview session.
