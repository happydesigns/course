## About this course

Build a page using Nuxt UI, then check its colors and keyboard navigation.

## What you will learn

- Give every page one clear purpose.
- Use semantic colors rather than hardcoded values.
- Make actions understandable with a keyboard and a screen reader.

::tip
You need basic Vue knowledge. No existing brand is required.
::

## Your learning path

Start with the lesson below. Try the two checkpoints and inspect the project file as you read. Progress in this example stays within the current preview session.
