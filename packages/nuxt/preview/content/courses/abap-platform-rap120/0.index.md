## What You'll Build

By the end of the workshop, you have a draft-enabled SAP Fiori elements Travel app built with the ABAP RESTful Application Programming Model. The business object has `Travel` and `Booking` nodes. Later sections add a calculated booking price, generated tests, customer validation, total price determination, and optional sightseeing tips through the ABAP AI SDK powered by ISLM.

## What You'll Learn

- Generate and review a transactional RAP business object and OData V4 UI service with SAP Joule for developers.
- Shape a Fiori elements UI with metadata extensions and behavior definitions.
- Explain and test CDS and ABAP logic with Joule-assisted workflows.
- Add RAP validations and determinations, then verify their behavior in the running app.
- Optionally call a large language model from ABAP through the ABAP AI SDK powered by ISLM.

## Before You Start

You need the latest ABAP Development Tools for Eclipse, access to a suitable ABAP system connected to SAP AI Core, and the appropriate ABAP Flight Reference Scenario. The guided setup follows SAP BTP ABAP environment and SAP S/4HANA Cloud Public Edition. For SAP-led events, use the system and sign-in instructions supplied by the instructors.

The optional sightseeing exercise additionally requires a configured intelligent scenario and access to the ABAP AI SDK powered by ISLM.

## Course Structure

Complete the setup and five required SAP exercises in order. The two optional exercises extend the finished application with AI-generated sightseeing tips and additional generator experiments. Each step ends with one or more result-based checkpoints, and your progress is stored in this browser.
