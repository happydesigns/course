# Basic Course

This tiny course demonstrates the generic `@happydesigns/course` format with prose, file snapshots, actions, validation hints, and code changes.

The rendered Nuxt UI-style course example now lives at `playground/content/courses/how-to-build-an-ai-chat.md` so the playground app can load it through Nuxt Content. The JSON file in this folder remains as a compatibility example for the core schema.

It is intentionally not SAP-specific and has no runtime AI dependency.
