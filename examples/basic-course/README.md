# Basic Course

This tiny course demonstrates the generic `@happydesigns/course` format with prose, file snapshots, actions, validation hints, and code changes.

The rendered course source now lives at `apps/docs/content/courses/basic.md` so the docs app can load it through Nuxt Content, matching the Nuxt UI blog authoring model. The JSON file in this folder remains as a compatibility example for the core schema.

It is intentionally not SAP-specific and has no runtime AI dependency.
