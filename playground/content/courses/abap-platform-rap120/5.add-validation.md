Save and activate. Use ADT Quick Fix on `validateCustomer` to add the validation method to behavior implementation class `ZBP_R_TRAVEL{{ $doc.input.groupId }}`.

Then place the cursor on the generated method implementation, choose **Predict RAP Business Logic**, and enter the method description.

::code-tree-intersection

```text [prompts/3.validate-customer.md]
Instantiate the helper class zcl_travel_helper_{{ $doc.input.groupId }}, then read the CustomerId field from the CDS view ZR_TRAVEL{{ $doc.input.groupId }}.

Check if the CustomerID is initial, and validate it using the zcl_travel_helper_{{ $doc.input.groupId }} helper class.

If the CustomerID is missing or invalid, append the key failed-travel. Also, add the key to reported-travel with a NEW_MESSAGE_WITH_TEXT error message.
```

```abap [ZRAP120_AI_{{ $doc.input.groupId }}/behavior/ZBP_R_TRAVEL{{ $doc.input.groupId }}.locals_imp.abap] {8-9,20-39}
CLASS LHC_ZR_TRAVEL{{ $doc.input.groupId }} DEFINITION INHERITING FROM CL_ABAP_BEHAVIOR_HANDLER.
  PRIVATE SECTION.
    METHODS:
      GET_GLOBAL_AUTHORIZATIONS FOR GLOBAL AUTHORIZATION
        IMPORTING
          REQUEST requested_authorizations FOR Travel
        RESULT result,
      validateCustomer FOR VALIDATE ON SAVE
        IMPORTING keys FOR Travel~validateCustomer.
ENDCLASS.

CLASS LHC_ZR_TRAVEL{{ $doc.input.groupId }} IMPLEMENTATION.
  METHOD GET_GLOBAL_AUTHORIZATIONS.
  ENDMETHOD.

  METHOD validateCustomer.
    DATA(lo_travel_helper) = NEW zcl_travel_helper_{{ $doc.input.groupId }}( ).

    READ ENTITIES OF zr_travel{{ $doc.input.groupId }} IN LOCAL MODE
      ENTITY Travel
        FIELDS ( CustomerID )
        WITH CORRESPONDING #( keys )
      RESULT DATA(lt_travel).

    LOOP AT lt_travel INTO DATA(ls_travel).
      IF ls_travel-CustomerID IS INITIAL OR
        lo_travel_helper->validate_customer( ls_travel-CustomerID ) = abap_false.
        APPEND VALUE #( %tky = ls_travel-%tky ) TO failed-Travel.
        APPEND VALUE #(
          %tky        = ls_travel-%tky
          %state_area = 'Validation'
          %msg        = new_message_with_text(
                          text     = 'Invalid or missing CustomerID'
                          severity = if_abap_behv_message=>severity-error
                        )
        ) TO reported-Travel.
      ENDIF.
    ENDLOOP.
  ENDMETHOD.
ENDCLASS.
```
