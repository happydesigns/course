Create package `ZRAP120_RAP_GEN_{{ $doc.input.groupId }}` with description `Play around with ABAP Cloud Generator`. Then start **Generate ABAP Repository Objects** and choose **OData UI Service from Scratch**.

Prompt guidelines recommend accuracy, enough domain detail, correct RAP terminology, and specific entity descriptions. The wizard generates draft-enabled OData V4 Fiori UI services by default unless the prompt says otherwise.

::code-tree-intersection

```text [prompts/6.generate-read-only-library.md]
Generate a read-only application.
Generate a library application. Create entities for library branches, book stock, user and borrowing information. Generate appropriate fields, at least 10 per entity. Use Prefix TST and project name My Library.
```

```text [prompts/7.generate-agencies-employees.md]
Generate a read-only application for managing agencies and employees.
The employee entity requires the fields employee_id, first_name, last_name, salary, and manager_id.
Use numerical text data type with length 8 like data types for the fields employee_id and manager_id.
Use character like data types for the other fields.
The field salary is a currency field.

Create the object names with the suffix '{{ $doc.input.groupId }}'.
```

::

Review the generated entity summary, click **Accept**, inspect and adjust fields, use preview before generation, select a transport request, and click **Finish**. Publish the generated service binding and preview the app from an entity set.
::course-checkpoint{id="generator-explored"}
You generated and reviewed at least one additional transactional application.
::
