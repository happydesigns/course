Open class `ZCL_TRAVEL_HELPER_{{ $doc.input.groupId }}`, switch to **Test Classes**, insert the `testClass` template with **Ctrl+Space**, rename the local test class to `LTCL_TRAVEL_HELPER_{{ $doc.input.groupId }}`, and remove default method `first_test`.

Right-click `ZCL_TRAVEL_HELPER_{{ $doc.input.groupId }}` and choose **Joule > Start Chat for ABAP Unit**. Use **Find Test-Unfriendly Dependencies**. The dependency on `/DMO/CUSTOMER` is identified, then the test double setup is generated.

::note
If Joule responds with `Currently there are no test classes for ...`, continue and copy the test class code shown in the exercise.
::

Add `validate_customer_success FOR TESTING` and use the test class below as the target state.

::code-tree-intersection

```abap [ZRAP120_AI_{{ $doc.input.groupId }}/classes/ZCL_TRAVEL_HELPER_{{ $doc.input.groupId }}.testclasses.abap] {5-20,24-51}
CLASS ltcl_travel_helper_{{ $doc.input.groupId }} DEFINITION FINAL FOR TESTING
  DURATION SHORT RISK LEVEL HARMLESS.

  PRIVATE SECTION.
    "! ABAP SQL test environment
    CLASS-DATA environment TYPE REF TO if_osql_test_environment.
    CLASS-METHODS:
      " setup test double framework
      class_setup,
      " stop test doubles
      class_teardown.

    METHODS:
      " rollback test doubles
      setup,

      "! Test helper method
      configure_db_testdoubles,

      validate_customer_success FOR TESTING.
ENDCLASS.

CLASS ltcl_travel_helper_{{ $doc.input.groupId }} IMPLEMENTATION.
  METHOD class_setup.
    environment = cl_osql_test_environment=>create(
      i_dependency_list = VALUE #( ( '/DMO/CUSTOMER' ) ) ).
  ENDMETHOD.

  METHOD class_teardown.
    environment->destroy( ).
  ENDMETHOD.

  METHOD setup.
    environment->clear_doubles( ).
    configure_db_testdoubles( ).
  ENDMETHOD.

  METHOD configure_db_testdoubles.
    DATA customer_stub_data TYPE STANDARD TABLE OF /dmo/customer.

    customer_stub_data = VALUE #(
      ( client = '100' customer_id = '000001' )
      ( client = '100' customer_id = '000002' )
      ( client = '100' customer_id = '000003' )
    ).
    environment->insert_test_data( customer_stub_data ).
  ENDMETHOD.

  METHOD validate_customer_success.
    DATA(cut) = NEW zcl_travel_helper_{{ $doc.input.groupId }}( ).
    DATA(result) = cut->validate_customer( '000001' ).

    cl_abap_unit_assert=>assert_equals( exp = abap_true act = result ).
  ENDMETHOD.
ENDCLASS.
```

::

Run the unit test. You can also try `validate_customer_failure` with the same approach.
