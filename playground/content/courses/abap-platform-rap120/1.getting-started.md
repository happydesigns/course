## Check the Prerequisites

You need the latest ABAP Development Tools for Eclipse, access to a suitable ABAP system connected to SAP AI Core, and the appropriate ABAP Flight Reference Scenario. This course follows SAP BTP ABAP environment and SAP S/4HANA Cloud Public Edition.

If you are attending an SAP-led event, use the supplied system handout and access details. A dedicated system may already contain the required reference scenario, so event-specific instructions take precedence over the generic setup below.

## Choose a Unique Group ID

Choose or receive a group ID before creating artifacts. Enter a group ID of at most three numbers and/or letters, such as `123`, `XY1`, or `ABC`, in the field above. The course then shows that value consistently in object names, file paths, code, and prompts.

If you choose your own ID, use **Open ABAP Development Object** or **Ctrl+Shift+A** in ADT and search for `zrap120_*ABC`, replacing `ABC` with your candidate. No result means the suffix is probably still available. Avoid `000`, which SAP commonly uses in examples and screenshots.

::course-checkpoint{id="group-id-selected" title="Group ID ready"}
Your unique group ID is selected and available in the target ABAP system.
::

## Connect ADT to the ABAP System

In ADT, create an ABAP Cloud Project if you do not already have one:

1. Open the **ABAP** perspective.
2. Create an **ABAP Cloud Project**.
3. Enter the ABAP service instance URL and click **Next**.
4. Use **Open Logon in Browser** and enter your credentials.
5. Return to ADT and click **Finish**.

If your assigned group ID changes, update the field above; the complete course and project view update automatically.

::course-checkpoint{id="abap-project-connected" title="ADT connected"}
The ABAP project is visible in ADT and you can browse its packages.
::

## Useful ADT Shortcuts

- **Ctrl+Shift+A** opens an ABAP development object.
- **Ctrl+1** opens Quick Assist for the current code position.
- **Ctrl+Space** opens code completion and templates.
- **Ctrl+F3** activates the current development object.
- **Ctrl+Shift+L** shows the complete ADT key assist.
