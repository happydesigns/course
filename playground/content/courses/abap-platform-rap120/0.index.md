## What You'll Build

By the end of the workshop, you have a draft-enabled SAP Fiori elements Travel app built with the ABAP RESTful Application Programming Model. The business object has `Travel` and `Booking` nodes. Later sections add a calculated booking price, generated tests, customer validation, total price determination, and optional sightseeing tips through the ABAP AI SDK powered by ISLM.

Start with the required exercises to build and test the application. The two optional exercises extend the finished result with AI-generated sightseeing tips and additional generator prompts.
