In RAP120, you generate the RAP business object and UI service first, then inspect and adjust the generated artifacts. The steps below follow that workflow: generate the application, review the generated objects, then add the ABAP and CDS changes used by the workshop.

The main artifacts are:

- `ZRAP120_AI_###/behavior/ZR_TRAVEL###.bdef`
- `ZRAP120_AI_###/behavior/ZBP_R_TRAVEL###.locals_imp.abap`
- `ZRAP120_AI_###/classes/ZCL_TRAVEL_HELPER_###.clas.abap`
- `ZRAP120_AI_###/cds/ZR_BOOKING###.asddls`
- `ZRAP120_AI_###/metadata/ZC_TRAVEL###.asddlx`
- `ZRAP120_AI_###/metadata/ZC_BOOKING###.asddlx`

## What We're Building

By the end of the workshop, you have a draft-enabled SAP Fiori elements Travel app built with the ABAP RESTful Application Programming Model. The business object has `Travel` and `Booking` nodes. Later sections add a calculated booking price, generated tests, customer validation, total price determination, and optional sightseeing tips through the ABAP AI SDK powered by ISLM.

The workshop sequence is:

- Getting Started
- Generate the transactional Travel app
- Enhance the CDS data model and create CDS unit tests
- Analyze the helper class and create ABAP unit tests
- Add a validation
- Add a determination
- Optionally add sightseeing tips through ABAP AI SDK powered by ISLM
- Optionally explore additional generator prompts

## Prerequisites

You need the latest ABAP Development Tools for Eclipse, access to a suitable ABAP system connected to SAP AI Core, and the appropriate ABAP Flight Reference Scenario. SAP BTP ABAP environment and SAP S/4HANA Cloud Public Edition are supported. SAP-led events may provide a dedicated system and access details.

Choose or receive a group ID before creating artifacts. The workshop uses `###` as the placeholder in object names. Replace every occurrence with a group ID of at most three numbers and/or letters, such as `123`, `XY1`, or `ABC`.

In ADT, create an ABAP Cloud Project if you do not already have one:

1. Open the **ABAP** perspective.
2. Create an **ABAP Cloud Project**.
3. Enter the ABAP service instance URL and click **Next**.
4. Use **Open Logon in Browser** and enter your credentials.
5. Return to ADT and click **Finish**.

Use ADT **Find/Replace** with **Ctrl+F** whenever the workshop asks you to replace `###`.

## Generate the RAP App

Create package `ZRAP120_AI_###` under `ZLOCAL`, with description `RAP AI Package ###`, and add it to favorite packages. This package contains the generated and adjusted artifacts.

Right-click package `ZRAP120_AI_###`, select **Generate ABAP Repository Objects**, choose **OData UI Service from Scratch**, and keep the package name. Paste the first prompt:

::code-tree-intersection

```text [prompts/1.generate-travel-service.md]
Create a transactional application for travel management with DRAFT.
Create the entity Travel based on the structure /DMO/TRAVEL_DATA.
The second entity is Booking based on /DMO/BOOKING_DATA.
The generated objects should end with suffix "###".
```

::

Accept the generated `Travel` and `Booking` entities, then add the workshop-specific fields:

::code-tree-intersection

```text [prompts/2.add-travel-fields.md]
Add Destination field for entity Travel, use /DMO/CITY as data element.
Add SightseeingsTips field for entity Travel, use /DMO/DESCRIPTION as data element.
Add DiscountedFlightPrice field for entity Booking, use /DMO/FLIGHT_PRICE as data element.
```

::

Before you generate the RAP business object, review the generated service configuration:

- `Travel` has `Destination` and `SightseeingsTips`.
- `Booking` has `DiscountedFlightPrice`.
- `BookingFee` and `TotalPrice` use `CurrencyCode`.
- `BookingFeeCurr` is removed.
- `DiscountedFlightPrice` and `FlightPrice` use `CurrencyCode`.
- `FlighPriceCurr` is removed.

Click **Next**, review the generated object preview, select a transport request, click **Finish**, and refresh the package with **F5** if needed.

::note

```abap [ZRAP120_AI_###/classes/ZCL_TRAVEL_HELPER_###.clas.abap] {6-15,23-42}
      IMPORTING iv_customer_id TYPE /dmo/customer_id

CLASS zcl_travel_helper_### IMPLEMENTATION.
  METHOD validate_customer.
    SELECT SINGLE
      FROM /dmo/customer
      FIELDS @abap_true AS line_exists
      WHERE customer_id = @iv_customer_id
      INTO @rv_exists.
  ENDMETHOD.

  METHOD get_booking_status.
    CASE iv_status.
      WHEN 'Booked'.
        rv_status = 'B'.
      WHEN 'New'.
        rv_status = 'N'.
      WHEN 'Cancelled'.
        rv_status = 'X'.
    ENDCASE.
  ENDMETHOD.

    " We will use the ABAP AI SDK powered by ISLM to call an LLM and generate sightseeing tips for a specific city.
  ENDMETHOD.
ENDCLASS.
```

## Enhance the Booking CDS View

Open CDS data definition `ZR_BOOKING###`. Replace the generated `DiscountedFlightPrice` calculation with carrier-based logic: 10 percent discount for `LH`, 15 percent for `AF`, and full price otherwise.

::code-tree-intersection

```abap [ZRAP120_AI_###/cds/ZR_BOOKING###.asddls] {20-25}
@AccessControl.authorizationCheck: #CHECK
@Metadata.allowExtensions: true
@EndUserText.label: '###GENERATED Core Data Service Entity'
define view entity ZR_BOOKING###
  as select from zbooking### as Booking

  association to parent ZR_TRAVEL### as _Travel on $projection.ParentUuid = _Travel.UUID
{
  key uuid          as UUID,
      parent_uuid   as ParentUUID,
      booking_id    as BookingID,
      booking_date  as BookingDate,
      customer_id   as CustomerID,
      carrier_id    as CarrierID,
      connection_id as ConnectionID,
      flight_date   as FlightDate,
      @Semantics.amount.currencyCode: 'CurrencyCode'
      flight_price  as FlightPrice,
      currency_code as CurrencyCode,
      @Semantics.amount.currencyCode: 'CurrencyCode'
      case
        when carrier_id = 'LH' then cast(flight_price as abap.dec(16,2)) * cast('0.90' as abap.dec(5,2))
        when carrier_id = 'AF' then cast(flight_price as abap.dec(16,2)) * cast('0.85' as abap.dec(5,2))
        else cast(flight_price as abap.dec(16,2))
      end           as DiscountedFlightPrice,

      _Travel
}
```

```text [prompts/3.validate-customer.md]
Instantiate the helper class zcl_travel_helper_###, then read the CustomerId field from the CDS view ZR_TRAVEL###.

Check if the CustomerID is initial, and validate it using the zcl_travel_helper_### helper class.

If the CustomerID is missing or invalid, append the key failed-travel. Also, add the key to reported-travel with a NEW_MESSAGE_WITH_TEXT error message.
```

```abap [ZRAP120_AI_###/behavior/ZBP_R_TRAVEL###.locals_imp.abap] {8-9,20-39}
CLASS LHC_ZR_TRAVEL### DEFINITION INHERITING FROM CL_ABAP_BEHAVIOR_HANDLER.
  PRIVATE SECTION.
    METHODS:
      GET_GLOBAL_AUTHORIZATIONS FOR GLOBAL AUTHORIZATION
        IMPORTING
          REQUEST requested_authorizations FOR Travel
        RESULT result,
      validateCustomer FOR VALIDATE ON SAVE
        IMPORTING keys FOR Travel~validateCustomer.
ENDCLASS.

CLASS LHC_ZR_TRAVEL### IMPLEMENTATION.
  METHOD GET_GLOBAL_AUTHORIZATIONS.
  ENDMETHOD.

  METHOD validateCustomer.
    DATA(lo_travel_helper) = NEW zcl_travel_helper_###( ).

    READ ENTITIES OF zr_travel### IN LOCAL MODE
      ENTITY Travel
        FIELDS ( CustomerID )
        WITH CORRESPONDING #( keys )
      RESULT DATA(lt_travel).

    LOOP AT lt_travel INTO DATA(ls_travel).
      IF ls_travel-CustomerID IS INITIAL OR
        lo_travel_helper->validate_customer( ls_travel-CustomerID ) = abap_false.
        APPEND VALUE #( %tky = ls_travel-%tky ) TO failed-Travel.
        APPEND VALUE #(
          %tky        = ls_travel-%tky
          %state_area = 'Validation'
          %msg        = new_message_with_text(
                          text     = 'Invalid or missing CustomerID'
                          severity = if_abap_behv_message=>severity-error
                        )
        ) TO reported-Travel.
      ENDIF.
    ENDLOOP.
  ENDMETHOD.
ENDCLASS.
```

```abap [ZRAP120_AI_###/classes/ZCL_TRAVEL_HELPER_###.clas.abap] {39-59}
CLASS zcl_travel_helper_### IMPLEMENTATION.
  METHOD validate_customer.
    SELECT SINGLE
      FROM /dmo/customer
      FIELDS @abap_true AS line_exists
      WHERE customer_id = @iv_customer_id
      INTO @rv_exists.
  ENDMETHOD.

  METHOD get_booking_status.
    CASE iv_status.
      WHEN 'Booked'.
        rv_status = 'B'.
      WHEN 'New'.
        rv_status = 'N'.
      WHEN 'Cancelled'.
        rv_status = 'X'.
    ENDCASE.
  ENDMETHOD.

  METHOD get_sightseeing_tips.
    DATA(system_prompt) = | You support by giving sightseeing tips for a given city. | &&
                          | Write a short summary of the 10 top most sightseeing tips | &&
                          | using a brief listing without a caption | &&
                          | It should be less 1000 characters. |.
    DATA(user_prompt) = |The city is { iv_city }.|.

    TRY.
      FINAL(api) = cl_aic_islm_compl_api_factory=>get( )->create_instance( islm_scenario = 'ZINTS_RAP120' ).
    CATCH cx_aic_api_factory INTO DATA(lx_api).
      rv_sightseeing_tips = ''.
    ENDTRY.

    TRY.
      FINAL(message_container) = api->create_message_container( ).
      message_container->set_system_role( system_prompt ).
      message_container->add_user_message( user_prompt ).
      rv_sightseeing_tips = api->execute_for_messages( message_container )->get_completion( ).
    CATCH cx_aic_completion_api INTO DATA(lx_completion).
      rv_sightseeing_tips = ''.
    ENDTRY.
  ENDMETHOD.
```
